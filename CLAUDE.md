# W Obiektywie — Landing Page

## Git Workflow
- **develop** — branch roboczy, tu pracujemy na co dzień
- **main** — produkcja, GitHub Pages deployuje z main
- Na polecenie "releasuj na produkcję" / "merguj" → merge develop do main, push, wróć na develop
- Nigdy nie commituj bezpośrednio do main

## Deploy
- GitHub Pages: https://agatawiktoriaolejniczak-jpg.github.io/w-obiektywie/
- Repo: https://github.com/agatawiktoriaolejniczak-jpg/w-obiektywie

## Stack
- Czysty HTML/CSS/JS (single page, no framework)
- Font: Lexend Deca (body, OG brand) + Playfair Display (nagłówki, ton W Obiektywie)
- Kolory OG brand: navy #2A3A6C, blue #337DC0, gray #EBECEC, #C5C6C6
- Akcent W Obiektywie: gold #C8A45A
- Server dev: `python3 -m http.server 8006`
